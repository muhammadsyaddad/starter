0. PURPOSE
--------------------------------------------------------------------------------
All list pages share the same table behaviour (search, filters, sort, actions,
pagination, empty state). Only the COLUMNS differ. Build one reusable
<BaseTable> once; each page only supplies:
    columns[]  +  toolbar config  +  pagination mode  +  footer noun

Notation:
  [sort]        column is sortable
  badge(ENUM)   value shown as a status/tag, possible values in Section 2
  date(FMT)     formatted date, format in Section 2
  2-line(a/b)   primary value a, secondary value b under it
  perm R/A      only visible with permission resource R, action A
  -> path       navigates to route
  fallback      shown when value empty


================================================================================
1. BASE TABLE CONTRACT
================================================================================
BaseTable<T>({
  data, columns, getRowId?,
  toolbar?: {
    search?:  { placeholder, mode: "client"|"server", fields?: (keyof T)[] },
    filters?: [{ columnId, allValue, allLabel, options: {value,label}[] }],  // exact match
    sort?:    { options: {value,label}[] } | { toggleField: keyof T },      // A-Z / Z-A
    primaryAction?: { label, onClick, permission? },
  },
  pagination: { mode: "client", pageSize }
            | { mode: "server", page, limit, total, onPageChange, onLimitChange? }
            | { mode: "none" },
  footerNoun?,                  // "Showing X of Y <noun>"
  loading?, error?, emptyText?,
  onRowClick?,
  rowSelection?: { canSelect?: (row)=>boolean, bulkActions?: [{label, onClick(rows)}] },
  expandable?: { render: (row)=>ReactNode, single?: boolean },
})

Column helpers needed (cell kinds used across the app):
  index, text, mono/id, 2-line, truncate(+tooltip), badge(enum), statusDot(active?),
  date(format), currency(IDR), number, progress(%), avatar(name), icon+text,
  link, select(checkbox), expand, actions(dropdown|inline)

actions item shape:
  { label, onClick(row), destructive?, permission?: {resource, action},
    visibleIf?: (row)=>boolean, confirm?: { title, description(row), confirmLabel } }


================================================================================
2. SHARED ENUMS / FORMATS / HELPERS
================================================================================
2.1 Status enums (one source per domain)
  ACTIVE_INACTIVE   active | inactive   (case-insensitive)
  ROLE              SUPER ADMIN | FINANCE MANAGER | FIELD ENGINEER | VIEWER
  TX_STATUS         pending | on_loan | return_pending | returned | returned_broke |
                    declined | return_rejected | partially_approved
  MAINT_TYPE        CORRECTIVE | PREVENTIVE
  MAINT_CHANNEL     remote | dispatch
  MAINT_STATUS      in_queue | in_progress | scheduled | completed("FINISH") |
                    forwarded | canceled
  INSTALL_STATUS    Scheduled | In Progress | Pending | Finish | Canceled
  PO_STATUS         APPROVED | PENDING | REJECTED
  TX_TYPE           INCOME | OUTCOME
  PROJECT_STATUS    Done | On Progress | Canceled
  DOC_TYPE          CA | FSR | BA | FINANCE | DRAFT
  DOC_STATUS        PENDING | ONGOING | FINISHED
  NOTIF_CATEGORY    MAINTENANCE | FINANCE | SYSTEM

2.2 Date formats
  DATETIME   "dd MMM yyyy HH:mm"
  DATE_MDY   "MMM d, yyyy"
  DATE_DMY   "dd/MM/yyyy"
  DATE_SHORT "dd MMM yyyy"
  RAW        already formatted string from API mapper

2.3 Currency
  IDR  Intl.NumberFormat("id-ID",{style:"currency",currency:"IDR",minimumFractionDigits:0})

2.4 Helpers to centralize (currently copy-pasted)
  formatStatus(s)        "on_loan" -> "On Loan" ; return_rejected -> "Declined"
  getOverallStatus(txs)  ToolTransaction[] -> pending | declined | returned |
                         return_pending | on_loan | partially_approved
  dueDateInfo(due,status)  FINISHED -> "Finished" ; overdue & PENDING ->
                         "Pending (Nd overdue)" ; overdue -> "Nd missed" ;
                         <=3 days -> "Due today" | "Nd left" ; else "Nd left"
  initials(name)         2-letter avatar text
